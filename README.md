# Sudoku-solver using backtracking
The aim of this project is to build a sudoku solver
using the backtracking algorithm

## How does it work?
We will write a sudoku as a 9 by 9 matrix and we'll
try to solve it

## How does backtracking work?
1. Pick empty cell
2. Try all numbers
3. Find one that works
4. Repeat
5. Backtrack
